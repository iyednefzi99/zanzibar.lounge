# Script Démo — Waitlist Gamifiée (90s)

## Objectif
Montrer la waitlist gamifiée : le client rejoint la file, gagne des points, et reçoit une notification quand une table se libère.

## Déroulé

### 0:00 — Problème (10s)
**Texte à l'écran :**
> "80% des clients partent quand ils voient la file d'attente"

**Visuel :** File d'attente physique, clients mécontents

---

### 0:10 — Solution (5s)
**Texte à l'écran :**
> "Zanzibar Lounge : transformez l'attente en expérience"

---

### 0:15 — Interface client (30s)
**Visuel :** Écran mobile de la waitlist

**Étape 1 :** Le client rejoint la waitlist
**Écran :**
> "Position #3 dans la file"
> "Temps estimé : 15 minutes"
> "Récompense : 10% de réduction si vous attendez 15 min"

**Étape 2 :** Le client gagne des points
**Écran :**
> "+50 points gagnés !"
> "Total : 350 points"
> "Prochaine récompense : Dessert gratuit (500 points)"

**Étape 3 :** Notification
**Notification WhatsApp :**
> "Une table est libre ! 🎉
> Réservez maintenant dans les 15 minutes.
> [Réserver maintenant]"

---

### 0:45 — Interface staff (20s)
**Visuel :** Dashboard staff avec file d'attente

**Voix off :**
> "Le staff voit la file en temps réel et peut notifier les clients d'un coup."

**Actions démo :**
1. Voir les 3 clients en attente
2. Notifier le prochain client
3. Voir les récompenses distribuées

---

### 1:05 — Résultats (15s)
**Texte à l'écran :**
> "-60% de no-shows"
> "+25% de satisfaction client"
> "3x plus de retours"

---

### 1:20 — Appel à l'action (10s)
**Texte à l'écran :**
> "Activez la waitlist gamifiée"
> "zanzibar-lounge.vercel.app"

## Technique
- Enregistrement écran mobile : Loom ou OBS
- Enregistrement dashboard : OBS Studio
- Transitions : Fondu enchaîné
- Musique : Lo-fi upbeat
